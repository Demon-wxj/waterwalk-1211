# 水上漂

按 J 或 /waterwalk 切换水面行走，服务端确认状态，客户端显示随脚步扩散的原创波纹。

分类：移动能力。原本地版本 `1.0.1-mc1.21.1`，运行目标 Minecraft **1.21.1 / Fabric / Java 21**。Mod ID：`waterwalk`。
