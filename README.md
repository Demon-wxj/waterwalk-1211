# 水上漂

切换水面行走，脚下显示随步伐扩散的波纹。状态由服务端确认。

Minecraft **1.21.1 / Fabric / Java 21**。源码版本 `1.0.1-mc1.21.1`，Mod ID：`waterwalk`。

按 **J** 或输入 `/waterwalk` 切换，也可以用 `/waterwalk on`、`/waterwalk off` 指定状态。客户端和服务器都要安装，只有客户端安装时无法在联机服务器上生效。
